About

I'm a Ph.D. student in the CORSys Lab advised by Prof. Michael Jantz. I work on computer systems, mostly garbage collection and memory management in OpenJDK's HotSpot JVM.

Research

  • Using Intel Cache Allocation Technology to partition LLC ways between GC and application threads, reducing GC-induced cache pressure.
  • Data tiering for ZGC: classifying object hotness and migrating objects between DRAM and persistent memory.
  • Letting managed runtimes respond to OS memory pressure by shrinking their heaps on demand.
